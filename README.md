# tap

Este repositorio incluye una página para GitHub Pages que redirige al enlace de Gemini compartido.

## GitHub Pages

1. Ve a **Settings > Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama principal y la carpeta **/(root)**.
4. Guarda los cambios.

La página quedará disponible en la URL de Pages del repositorio y redirigirá automáticamente al enlace de Gemini.
